# Operations

**Purpose**: Post-construction activities including UI/UX refinements, screen content refinements, deployment, monitoring, and maintenance

**Status**: Active — UI/UX Refinements and Screen Content Refinements stages implemented

## Active Stages

### UI/UX Refinements (CONDITIONAL)
**Execute IF**:
- Application is functional (CONSTRUCTION complete or existing working app)
- User requests visual/design improvements
- Design references or inspiration available

**Skip IF**:
- New feature development needed (use CONSTRUCTION)
- No UI changes requested

**Execution**: Load `operations/ui-ux-refinements.md` for detailed steps

### Screen Content Refinements (CONDITIONAL)
**Execute IF**:
- Application has screen-based content flows (lessons, tutorials, onboarding, etc.)
- User requests text/copy improvements to existing screens
- Content exists but needs clarity, tone, or messaging adjustments

**Skip IF**:
- Creating new content from scratch (use CONSTRUCTION)
- Visual/design changes needed (use UI/UX Refinements)

**Execution**: Load `operations/screen-content-refinements.md` for detailed steps

**Key Distinction**: 
- **UI/UX Refinements** = how screens LOOK (colors, typography, layout, components)
- **Screen Content Refinements** = what screens SAY (headlines, body text, prompts, instructions)
